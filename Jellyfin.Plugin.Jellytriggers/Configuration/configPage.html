Jellytriggers

Surfaces personalized Does The Dog Die content warnings on the movie detail page, filtered to each viewer's saved triggers.

Step 1 — install File Transformation

Jellytriggers loads its pane through the File Transformation plugin. With it installed, Jellytriggers automatically registers its index.html hook on server startup — no script tags to paste, no jellyfin-web files to edit.

Add https://www.iamparadox.dev/jellyfin/plugins/manifest.json as a plugin repository in Settings → Plugins → Repositories, install File Transformation from the catalogue, then restart your Jellyfin server. After the restart, refresh this page and you should see “detected” below.

Step 2 — tell each viewer to add their DTDD API key

Each Jellyfin user supplies their own DTDD API key (DTDD will personalize responses to that key's account). Once the script tag above is loaded, the pane on any movie page will prompt the viewer to set their key the first time it appears.

There is intentionally no in-Jellyfin category picker — viewers curate their triggers on doesthedogdie.com itself, and Jellytriggers honors whatever they have marked there.

Cache settings

How long to remember the Jellyfin-item → DTDD-media-id mapping for a hit. Default 30 days.
How long to remember “not on DTDD” before re-trying. Default 7 days.
How long to cache the per-user filtered pane content. Lower values pick up changes the user makes on doesthedogdie.com sooner. Default 24 hours.
